# Sistema de Conta Corrente - POO

## 📌 Sobre o Projeto

Este projeto é um sistema simples de **Conta Corrente** desenvolvido em **Python** utilizando conceitos de **Programação Orientada a Objetos (POO)**.

O sistema simula operações básicas de uma conta bancária, permitindo realizar ações como:

- depósitos
- saques
- consulta de saldo

O objetivo do projeto é praticar conceitos fundamentais de orientação a objetos, organização de código e lógica de programação.

Este projeto foi desenvolvido com **objetivo acadêmico**, como parte dos estudos em programação.

---

## 🧠 Conceitos de Programação Utilizados

Durante o desenvolvimento do projeto foram aplicados conceitos importantes de **POO**, como:

- Classes
- Objetos
- Métodos
- Atributos
- Encapsulamento
- Organização da lógica do sistema

---

## ⚙️ Funcionalidades do Sistema

O sistema permite executar as seguintes operações:

- Criar uma conta corrente
- Depositar dinheiro
- Sacar dinheiro
- Consultar saldo da conta
- Verificar limite disponível

## 📂 Estrutura do Projeto

Sistema_contacorerrente.POO/
